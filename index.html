Ficha Técnica del Software

1. Producto:
Nombre del Producto
Aplicativo Web de Ahorro y Finanzas para Estudiantes Universitarios
URL y Versión
https://www.ahorrou-app.net
Versión: 1.0
2. Descripción del Producto:
Objetivo y Descripción del producto:
Sistema web diseñado para que los estudiantes universitarios gestionen sus finanzas personales, registrando ingresos y gastos diarios para mantener su estabilidad económica
Beneficio:
Fomenta el hábito del ahorro, previene crisis financieras a mitad de semestre y facilita reportes claros de gastos innecesarios.
3. Especificaciones Técnicas:
Requisitos del sistema (servidor):
Hardware
Procesador compatible, mínimo 2 GB de RAM y almacenamiento adaptable en nube o local.
Software y Rendimiento:
Servidor web con tiempos de respuesta menores a 2 segundos por consulta.
Lenguajes de programacion utilizados:
Python / JavaScript / SQL
Requisitos del sistema (cliente):
Hardware:
Compatible con cualquier PC, portátil o dispositivo móvil con conexión a red inalámbrica.
Software Requerido:
Navegador web moderno y actualizado como Google Chrome, Firefox, Microsoft Edge, Safari
4. Componentes y Módulos Principales:
Módulos del Software:
  • Autenticación: Perfiles y seguridad:
  • Registro: Ingresos y egresos (Frontend).
  • Procesamiento: Lógica y balances (Backend).
  • Base de Datos: SQL
Accesorios Adicionales:
Panel de estadísticas gráficas y opción de exportar los reportes a formato CSV/PDF para análisis financiero avanzado del estudiante.
5. Instrucciones de Uso y Montaje:
Guia de instalación:
Subir los archivos fuente al servidor web configurado, importar el script SQL de la base de datos y ajustar las variables de conexión.
Instrucciones de Uso
El estudiante ingresa a la plataforma mediante credenciales, registra su capital inicial y actualiza diariamente sus transacciones.
6. Almacenamiento y Mantenimiento
Almacenamiento de Datos
Se almacena toda tu información de forma automática y continua en una base de datos SQL. Así, aunque tu computador falle o se borre algo por error, tus datos siempre estarán protegidos y listos para recuperarse en minutos.
Mantenimiento y Cuidado
Cada quince días se reliza una afinación del motor de la base de datos para que tus búsquedas sean rápidas, actualizamos el sistema con las últimas mejoras de seguridad y limpiamos los archivos basura acumulados para mantener el servidor ligero y eficiente
7. Normas y Certificaciones
Desarrollado aplicando buenas prácticas de programación, control de versiones con Git y normas básicas de seguridad web para proteger los datos de los usuarios.
