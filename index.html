Ficha Técnica del Software

1. Identificación del Producto
Nombre del Producto Aplicativo Web de Ahorro y Finanzas para Estudiantes Universitarios
URL
https://www.ahorrou-app.net Versión: 1.0
2. Descripción del Producto
Objetivo del Sistema Sistema web diseñado para que los estudiantes universitarios gestionen sus finanzas personales, registrando ingresos y gastos diarios para mantener su estabilidad económica.
Beneficio Principal Fomenta el hábito del ahorro, previene crisis financieras a mitad de semestre y facilita reportes claros de gastos innecesarios.
3. Especificaciones Técnicas
Requisitos del Sistema (Servidor)
Hardware Procesador compatible, mínimo 2 GB de RAM y almacenamiento adaptable en nube o local.
Software y Rendimiento Servidor web configurado para ejecutar el backend en Python, garantizando tiempos de respuesta menores a 2 segundos por consulta.
Lenguajes de programacion utilizados Python / JavaScript / SQL
Requisitos del Sistema (Cliente)
Hardware Compatible con cualquier PC, portátil o dispositivo móvil con conexión a red inalámbrica.
Software Requerido Navegador web moderno y actualizado como Google Chrome, Firefox, Microsoft Edge, Safari
4. Componentes y Módulos Principales
Modulos del Software
  • Autenticación: Perfiles y seguridad
  • Registro: Ingresos y egresos (Frontend)
  • Procesamiento: Lógica y balances (Backend)
  • Base de Datos: SQL
Herramientas Adicionales Panel de estadísticas gráficas y opción de exportar los reportes a formato CSV/PDF para análisis financiero avanzado del estudiante.
5. Instrucciones de Uso y Montaje
Guía de Instalacion Subir los archivos fuente al servidor web configurado, importar el script SQL de la base de datos y ajustar las variables de conexión.
Instrucciones de Uso El estudiante ingresa a la plataforma mediante credenciales, registra su capital inicial y actualiza diariamente sus transacciones.
6. Almacenamiento y Mantenimiento
Almacenamiento de Datos Los datos del usuario se almacenan de forma automática y continua en una base de datos SQL, garantizando el respaldo y la recuperación de la información ante fallos del sistema.
Mantenimiento Cada quince días se realiza mantenimiento y optimización de la base de datos para que las búsquedas sean rápidas, actualizamos el sistema con las últimas mejoras de seguridad y limpiamos los archivos basura acumulados para mantener el servidor ligero y eficiente.
7. Normas y Certificaciones
Estandares Aplicados Desarrollado aplicando buenas prácticas de programación, control de versiones con Git y normas básicas de seguridad web para proteger los datos de los usuarios.
